## 🎯 COMO USAR ESTE ROADMAP

### Atualizar Progresso
```
1. Completar uma tarefa
2. Marcar com ✅
3. Atualizar DATA_CONCLUSAO
4. Fazer commit: "docs: update roadmap progress"
5. Push para GitHub
```

### Rastrear Onde Paramos
```
Sempre olhe para:
├─ Milestone atual
├─ Status de cada tarefa
└─ Próximo passo imediato

Exemplo: Se estamos em M1.2, sabemos que:
- M1.1 está completo
- M1.2 precisa: push + GitHub Pages
- Próximo após M1.2: M1.3 (testes)
```

### Comunicar Mudanças
```
Se mudar plano:
1. Atualizar este roadmap
2. Criar GitHub Issue: "RFC: Mudança no roadmap"
3. Discutir na comunidade
4. Implementar
```
