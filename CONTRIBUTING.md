# 🤝 Como Contribuir

## Para Começar

1. Fork este repositório
2. Criar uma branch: `git checkout -b feature/sua-feature`
3. Fazer mudanças
4. Commit: `git commit -m "feat: descrição"`
5. Push: `git push origin feature/sua-feature`
6. Abrir Pull Request

## Áreas com Necessidade

- 🐛 Bugfixes
- ✨ Novas features
- 📖 Documentação
- 🎨 UI/UX improvements
- ✅ Testes

## Código de Conduta

Respeitar todos os contribuidores. Sem tolerância para assédio.
