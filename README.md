# 🎙️ Makavoice - Voice Cloning & Text-to-Speech

Voice cloning and text-to-speech web application.

## 🚀 Features

- 🎤 Gravação de voz
- 🤖 Clonagem com IA Local
- 💬 Síntese de áudio
- 📥 Download MP3/WAV
- 📱 PWA instalável
- 🔌 Funciona offline

## 📱 Como Usar

1. Abrir: https://josemar14.github.io/Makavoice-Clone/
2. Gravar sua voz (30-60 segundos)
3. Clonar voz
4. Digitar texto
5. Criar áudio
6. Baixar ou usar!
